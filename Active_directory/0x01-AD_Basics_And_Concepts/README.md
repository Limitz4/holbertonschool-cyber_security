# Active Directory Fundamentals

## Overview

This directory documents guided Active Directory (AD) exercises focused on domain structure, identity objects, service accounts, and attributes that administrators need to understand when reviewing a Windows enterprise environment.

## Learning Topics

- Domain reconnaissance and understanding core AD information.
- Users, groups, computers, and their relationships in a domain.
- Identifying the role and configuration of service accounts.
- Understanding the security significance of readable directory attributes.
- Exploring how domain and host configuration information supports defensive review.

## Repository Contents

The files `0-flag.txt` through `4-flag.txt` are **lab verification artifacts** corresponding to guided tasks. They are not PowerShell scripts, exported AD objects, or complete investigation reports. Their values are intentionally not shown in this README.

## Skills Practiced

- Understanding the structure and purpose of Active Directory.
- Recognizing identity and configuration information relevant to IT operations.
- Relating directory attributes to exposure, access control, and administration.
- Documenting results from an isolated Windows/AD practice environment.

## Defensive Takeaways

- Maintain accurate inventories of domain accounts and privileged groups.
- Limit access to sensitive account and directory attributes where appropriate.
- Review service-account permissions and rotate credentials according to policy.
- Monitor configuration changes to important identity infrastructure.

## Scope

This project represents learning exercises performed in an authorized lab. The available repository artifacts do not independently reproduce an Active Directory assessment or demonstrate compromise of a real domain.
